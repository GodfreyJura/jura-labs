## Running Locally

Clone the repository:

    git clone https://github.com/GodfreyJura/jura-labs.git

Move into the project:

    cd jura-labs

Open `index.html` in a browser.

The project does not require a backend server or package installation.

## Deployment

The website is deployed using Vercel and connected to the GitHub repository.

Every update can be committed and pushed through Git, allowing the deployed site to stay synchronized with the repository.

## Development Philosophy

I believe the best way to learn software development is to build, break, debug, and improve real projects.

My focus is not simply on collecting technologies. I want to understand how software works underneath the interface, how systems communicate, how data moves through an application, and how individual components become a complete product.

This portfolio will continue evolving as I build larger and more capable systems.
